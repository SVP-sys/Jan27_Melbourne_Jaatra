# Melbourne trip site

Single-page site (`index.html`) published with GitHub Pages and shared with the group by link.

## Privacy defaults

- Every published HTML page must keep `<meta name="robots" content="noindex, nofollow, noarchive">` in its `<head>`. Do not remove it unless Sunny asks.
- Do not add a `robots.txt` that blocks crawlers: blocked crawlers never see the noindex tag, so the page could still be listed.
- Never put booking references, payment details, passenger names, room numbers or other private details on the page. The repo and the site are public.
- Flight and transfer details live in the `TRIP` object in `index.html`; edit them there only.

## Before creating a new app or connecting a new repo

Ask Sunny whether it should be public or private before creating it, and explain the impact. On the free GitHub plan, GitHub Pages only works from a public repo.
